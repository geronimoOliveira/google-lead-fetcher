# Google Lead Fetcher

Temos essa solução via N8N, mas não achei fácil/intuitivo para qualquer pessoa extrair leads do Google.

Quero criar uma solução simples e fácil de utilizar e que o remix seja de fácil adaptação para outros usuários utilizarem.

Organize possibilidades de solução para isso.
